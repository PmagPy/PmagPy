# A VFTB file from La Garrotxa

Unmodified copy from: Vernet Tarragó, E. (2026). *Raw data of La Garrotxa Volcanic Field (NE Iberia) Pleistocene lava-flows* [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20326424 (CC BY 4.0), for Vernet et al. (2026), *Geologica Acta*, 24.15, https://doi.org/10.1344/GeologicaActa2026.24.15. It is in a folder of its own, so that tests reading `vftb_magic` leave it out.

| File | Curve | What it exercises |
| --- | --- | --- |
| `GTX0308B_500.rmp` | magnetization against temperature in about 35 mT, heated to 499 °C (500 in the file name) and cooled (a thermal-stability cycle) | measured at temperature in the field: `meas_temp`, `meas_field_dc` |
