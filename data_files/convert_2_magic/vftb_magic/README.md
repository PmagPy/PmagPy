# VFTB example files

Variable field translation balance (VFTB) measurements of one sample, as written by the instrument software, for `convert_2_magic.vftb` and its tests. The extension gives the kind of curve.

| File | Curve |
| --- | --- |
| `PRG1-2.irm` | IRM acquisition |
| `PRG1-2.coe` | back-field (DC) demagnetization of the IRM |
| `PRG1-2.hys` | hysteresis loop |
| `PRG1-2.rmp` | magnetization against temperature, heating and cooling |

The files are unmodified copies from: Calvo-Rathert, M., Carrancho, Á., Morales, J., Pérez, N., & Caccavari, A. (2021). Rock-magnetic, paleomagnetic and multimethod paleointensity data from an upper Miocene lava flow sequence from São Vicente (Cape Verde) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.5553392 (CC BY 4.0).
