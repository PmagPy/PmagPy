# ThellierTool files from La Garrotxa

Two Thellier-Coe files (laboratory field 40 μT), unmodified copies from:

Vernet Tarragó, E. (2026). *Raw data of La Garrotxa Volcanic Field (NE Iberia) Pleistocene lava-flows* [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20326424 (CC BY 4.0), for Vernet, E., Calvo-Rathert, M., Beamud, E., Bógalo, M.-F., Carrancho, Á., Planagumà, L., & Martí, J. (2026), *Geologica Acta*, 24.15, https://doi.org/10.1344/GeologicaActa2026.24.15

They are in a folder of their own, so that the tests that convert the whole `tdt_magic` folder leave them out.

| File | What it exercises | Published result (Table III of the paper) |
| --- | --- | --- |
| `GTX0206B1.TDT` | extension in capitals; Windows line ends; in-field steps along -Z | 200–540 °C, N 12, β 0.074, f 0.71, q 8.29, B 30.10 μT |
| `LTD_GTX02061.TDT` | the same, with a low-temperature demagnetization after each step; the specimen column reads `45. GTX02061`, a name with a space | 200–520 °C, N 11, β 0.037, f 0.78, q 17.61, B 26.91 μT |

The moments are magnetizations in A/m: they are of the order of the volume-normalized NRMs in the 2G files of the same cores.
